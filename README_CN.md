### 简介
这是一个功能强大的《无主之地4》存档修改器，旨在提供全面的存档编辑功能。完全免费，支持中英文切换。
该工具允许你修改角色数据、背包物品、解锁游戏内容，即时生成和定制武器装备，并提供强大的代码转换和生成功能。

---

### 主要功能

#### 存档管理
- 自动扫描 Steam 和 Epic 游戏存档目录并识别对应的用户 ID。
- 支持 Steam 和 Epic 平台的 64位 ID 解密与加密。
- 支持 `.sav` 文件的打开、保存及另存为。
- 自动备份原存档。
- 提供由实际修改触发的自动保存、原子写入、上一版本轮转备份与异常退出恢复。

#### 角色编辑
- 修改角色名称、当前职业。
- 自定义难度设置。
- 修改角色等级、经验值 (XP)。
- 修改专精等级 (Spec Level) 和累计专精经验值。
- 修改金钱 (Money) 和镒矿 (Eridium)。
- 在 Profile 存档中修改当前全部 Vault Card 代币余额。
- 一键同步背包内所有物品等级至当前角色等级。

#### 可选在线模式
- 通过另行分发的 `BL4 Live` SDK Mod 与游戏本地连接。
- 无需打开存档即可读取当前角色、背包和银行内容。
- 支持按稳定物品身份实时覆写、原生生成、未装备背包物品完整 identity 发布，以及已装备物品 Actor 的验证重建。
- 支持在线配装保存/应用与恢复锁，并提供 Vault Card、货币、弹药、容量、FOV、武器倍率、位置、失物和专属掉落等运行时控制。

#### 解锁与预设
提供多种一键解锁功能：
- 使用可随游戏内容更新的内置离线预设数据。
- 移除地图迷雾、发现所有地点、解锁所有安全屋。
- 解锁所有收集品、完成所有挑战、完成所有成就。
- 跳过剧情任务、跳过所有任务。
- 一键满级 (60级)、最大化储物格代币 (SDU)、补满弹药。
- 解锁密藏大门、解锁所有载具、解锁所有专精、解锁 UVHM 模式。
- 根据当前游戏数据解锁全部 Vault Card 永久奖励。
- 解锁/最大化所有内容 (Unlock/Max Everything)。

#### 物品与背包管理
- 查看和管理背包中的物品。
- 完全离线解析所有类型物品的前缀和名称。
- 完全离线解析武器数值，包括伤害、精准度、射速、装填时间、弹匣容量、DPS、暴击伤害、弹药消耗、爆炸范围、开镜时间和装备时间。
- 为武器、手雷、护盾、修复套件、重武器、职业模组和强化模组显示接近游戏内样式的悬浮物品卡及离线解析数据。
- 为物品设置 Flag（普通、收藏、垃圾、编组1-4）。
- 直接添加 Base85 或解码格式的物品代码到背包。
- 从背包中读取物品进行修改或复制序列号。

#### 装备生成与编辑
拥有独立的标签页，用于深度定制各类装备：
- **武器编辑器 (Weapon Editor)**: 搜索现有武器、查看实时数值，并通过可筛选配件目录修改部件、皮肤、元素、珠光覆盖和其他属性；可选显示内部字段，并通过枪管模型标识区分同模型与跨模型附件。
- **武器生成器 (Weapon Gen)**: 从头生成自定义武器，提供实时数值预览、响应式配件选择器和具体的配件效果倍率。
- **God Roll 优化器**: 按元素、枪管、托格模式、部件组数量和搜索预算，在合法或跨厂构筑中寻找高分组合，并可将结果加入背包。
- **职业模组 (Class Mod)**: 通过可搜索目录自定义职业、稀有度、技能加成和被动专长，支持职业与三色技能树筛选、描述和已选状态高亮。
- **强化模组 (Enhancement)**: 自定义厂商、稀有度、专长堆叠。
- **手雷 (Grenade)**: 自定义厂商、等级、稀有度、专长、元素、引信等。
- **护盾 (Shield)**: 自定义厂商、等级、稀有度、护盾类型（能量/护甲）、专长。
- **修复套件 (Repkit)**: 自定义前缀、抗性、固件、专长。
- **重武器 (Heavy Weapon)**: 自定义枪管、元素、固件、附件等。
- 非武器编辑器可从背包现有物品或 Base85 序列载入可编辑副本，并锁定厂商/职业身份以保证安全重建。
- 武器及四类装备编辑器提供自然生成规则、配件数量提示、实时数值预览和“手气不错”合法随机生成。
- 所有生成器均支持直接“加入背包”或“复制序列号”。

#### 转换器与高级工具
- **代码转换**: 支持 Base85 编码与 Deserialize (解析后) 数据互转。
- **批量处理**: 批量转换代码，批量将代码列表导入背包。
- **遍历生成器**: 支持通过设定数值范围批量生成物品序列（如生成所有皮肤、遍历所有部件组合）。
- **序列检视器**: 解析单条 Base85 或解析后序列，显示物品概要、配件 ID、名称、效果、合法性规则和物品卡，并支持导出 JSON 或卡片图片；内置从当前游戏数据导出的官方初始配置、任务/NPC 武器和内部样本预设，并标注来源场景及安全限制。
- **YAML 编辑器**: 提供可编辑懒加载树、源码与分屏视图，支持搜索、内联校验、撤销/重做、变更高亮、序列预览、跳转物品编辑器和背包槽位范围删除。

### 如何构建 (Build)

如果你想从源码构建可执行文件 (.exe)，请确保已安装 Python，并运行项目根目录下的 `pyinstaller_config.py` 脚本。

该脚本会自动处理依赖、收集所需的资源文件（如图片、JSON、CSV 等），并调用 PyInstaller 生成 `dist/BL4SaveEditor.exe`。

**步骤:**

1.  安装依赖:
    ```bash
    pip install pyinstaller pyyaml pycryptodome PyQt6 pandas
    ```
2.  运行构建脚本:
    ```bash
    python pyinstaller_config.py
    ```
3.  脚本运行完成后，生成的可执行文件将位于 `dist` 文件夹中。

### 使用说明
1. 打开软件，程序会自动扫描默认存档路径。
2. 选择存档并根据提示输入对应的 64位 ID（通常会自动检测，如需手动输入请填入 Steam ID 或 Epic ID）。
3. 加载成功后，即可在各个标签页进行修改。
4. 修改完成后点击“保存”即可生效。
5. 建议在修改前手动备份存档文件，虽然软件会自动创建备份。

### 常见问题排查

#### "The ordinal XXX could not be located in dynamic link library" 错误
如果启动程序时遇到此错误：

1. **验证文件完整性**：确保文件大小与官方发布版本一致（约70MB左右）。如果文件明显偏小，请从官方渠道重新下载。
2. **暂时关闭杀毒软件**：部分杀毒软件可能会修改或隔离可执行文件的某些部分。
3. **安装 Visual C++ 运行库**：下载并安装 [Microsoft Visual C++ Redistributable 2022 (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)。
4. **以管理员身份运行**：右键点击程序，选择"以管理员身份运行"。
5. **Windows 7/8 用户**：本程序针对 Windows 10+ 设计，旧版 Windows 可能缺少必要的系统组件。
